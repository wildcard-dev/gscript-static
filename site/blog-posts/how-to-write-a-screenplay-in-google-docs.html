How to Write a Screenplay in Google Docs

G-Script Team
August 14, 2026
GUIDE

Most first-time screenwriters don't start in screenwriting software. They start in Google Docs — because it's free, it's already open in another tab, and it's where they write everything else, from school papers to blog drafts to the group doc for a friend's wedding toast. If that's you, you don't need to switch tools to write a properly formatted screenplay. You need to know how Google Docs handles screenplay format, and where it needs a little help.

This guide walks through three ways to write a screenplay in Google Docs — by hand, with a static template, and with an add-on that formats as you type — plus a step-by-step walkthrough of writing your first scene correctly.

Why writers default to Google Docs

It's free, it's familiar, and — maybe most importantly if you're not writing alone — it's built for real-time collaboration. If you're working with a co-writer, comments, suggested edits, and live cursors mean you can both be in the same scene at the same time without emailing files back and forth. Standalone screenwriting software supports collaboration too, but it usually means both of you learning a new tool and paying for a license (or licenses). Google Docs collaboration, most screenwriters already have muscle memory for.

Option 1: The manual way — setting margins, tabs, and styles by hand

You can absolutely format a screenplay in Google Docs using nothing but Format menu settings: a 12pt Courier New font, custom margins (1.5" left, 1" right/top/bottom), and manually-set tab stops for character cues and dialogue. Some writers build out custom paragraph styles (Format → Paragraph styles) for scene headings, action, and dialogue so they can apply them with one click instead of resetting margins by hand every time.

The problem isn't that this is impossible — it's that it doesn't hold up over a full draft. The moment you paste in a note from somewhere else, copy a scene from another doc, or just get moving fast on a scene, indents and spacing drift. By page 40, half your scene headings are formatted slightly differently than the other half, and you're stuck doing a manual pass to fix it — usually right before you wanted to send the script to someone.

Option 2: The template way — using a pre-built Docs template

A step up from starting blank: download a pre-formatted Google Docs screenplay template (a title page plus a scene or two already styled correctly) and write into it. This solves the blank-page problem and gives you a formatting reference to copy from.

The limitation is that a template is static. It shows you what correct format looks like on the page you started with, but it doesn't enforce anything as you keep writing. Add a new scene, and you're back to manually applying the right paragraph style or tab stops yourself — the template helps you start right, not stay right.

Option 3: The tool way — add-ons that auto-format as you type

The category that solves the drift problem without leaving Google Docs is a screenwriting add-on: software that plugs into Docs and automatically applies the correct scene heading, action, character cue, and dialogue formatting as you type — no manual tab stops, no paragraph styles to remember. Hit enter after a character cue and it knows the next line is dialogue. Type "INT." and it knows you're starting a scene heading.

Step-by-step: writing a scene in Google Docs with correct format

Here's the manual version of the process, so you understand what's actually happening under the hood (a tool like G-Script does these steps for you automatically):

  1. Set your font and margins first. 12pt Courier New (or Courier Prime), 1.5" left margin, 1" on the other three sides. Do this before you start typing, not after.
  2. Type your scene heading in caps: INT. LOCATION - DAY. Left-aligned, no indent.
  3. Drop to a new line for action. Full-width, single-spaced, present tense: "Maya sits alone at a corner table."
  4. When a character speaks, tab in to about 3.7" and type their name in caps: MAYA.
  5. Press enter, then indent dialogue to roughly 2.5" from each margin and write the line in normal sentence case.
  6. Repeat for each new speaker or scene, re-capitalizing every character cue and resetting the scene heading format each time a new location or time of day starts.

Do that consistently for 100 pages by hand, and you'll understand exactly why an auto-formatting tool exists.

The co-writing angle: format stays correct when a partner edits live

If you're writing with a co-writer — which is common for first and second scripts — Google Docs' live collaboration is a real advantage over standalone software, where simultaneous editing is often clunkier or requires both people to have the same paid license. The catch is that manual formatting gets harder to maintain with two people typing, not easier: your partner's tab stops and paragraph styles won't always match yours, and drift compounds faster.

This isn't a separate problem from the one above — it's the same problem, just with two writers instead of one. An add-on that formats as you type solves it the same way: whoever's typing, the format comes out consistent, because it's not being hand-set by either of you.
