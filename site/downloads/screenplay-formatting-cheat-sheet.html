Screenplay Formatting Cheat Sheet

Every core formatting rule, on one page — so you never have to guess.

1. The five core elements

Element Format
Scene headingALL CAPS. INT. or EXT. + location + — DAY or — NIGHT. Left-aligned, no indent.
ActionPresent tense. Full width of the margin. Single-spaced.
Character cueALL CAPS. Centered ~3.7" from the left margin.
DialogueSentence case. Centered under the cue, ~2.5" margins on each side.
ParentheticalIn parentheses, directly under the character cue. Used sparingly — 2-3 words max.

2. Page setup

  • Font: 12pt Courier or Courier Prime
  • Margins: 1.5" left, 1" right/top/bottom
  • Page numbers: top-right corner, starting on page 2

3. Title page format

  • Title centered, roughly ⅓ down the page (all caps or title case)
  • "Written by" directly beneath the title
  • Writer's name beneath that
  • Contact info (email, phone) in the bottom-right corner
  • No artwork, no synopsis, no extra pages

4. Page count cheat sheet (1 page ≈ 1 minute)

Format Typical page count
Feature film90–120 pages
TV drama (hour-long)55–65 pages
TV comedy (half-hour)25–35 pages
Short filmUnder 15–20 pages

5. Five mistakes that get scripts passed over

  1. Wrong font/size (throws off the page-to-minute math)
  2. Camera directions in a spec script (PAN TO:, CLOSE ON:)
  3. Overwritten, dense action lines
  4. Inconsistent scene heading wording for the same location
  5. An overdesigned or missing title page
